# Flow Youtube Chat Lite

YouTube のライブチャットを、ニコニコ動画のように動画の上へ流すユーザースクリプトです。
[Flow Youtube Chat](https://greasyfork.org/scripts/411442)（更新停止）の機能を参考に、軽量版として新しく書き直しました。

## 特徴

- **チャット欄を開かなくても流れる**：チャット欄の表示を読み取らず、YouTube の内部 API からコメントを直接取得します
- **モバイル表示（m.youtube.com）にも対応**
- **軽量**：1 ファイル・外部ライブラリなし（元のスクリプトは 750KB、こちらは約 59KB）
- ライブとアーカイブの両方に対応。アーカイブはシークに、ライブは巻き戻しに追従します（ライブはページを開いてから受信したコメントの範囲）
- 設定のバックアップ（書き出し・読み込み）
- 日本語の設定画面（文字の大きさ・速さ・不透明度・流す範囲・NG ワード / NG ユーザーなど）
- 指定したユーザーのコメントを強調（2 種類・複数指定可）
  - 紫：アイコンと名前付きの紫で流す
  - 固定：流さずに画面下へ固定表示（新しいものが上に積み上がる）。配信者・モデレーターも固定表示にできる
- 設定はデスクトップ表示とモバイル表示で共通（拡張の保存領域を使う）
- 設定画面の「最近コメントした人」から、タップで紫・固定・NG に追加 / 解除
- 同じコメントの連投を「×N」にまとめる、絵文字・スタンプだけのコメントを流さない（選択式）
- スーパーチャットを大きく・ゆっくり流す（選択式）
- アーカイブのコメントの多い場面をシークバーの上にグラフ表示（選択式。全コメントを読み込むため通信量が多い）
- 速さの自動調整、ライブ映像の遅れに合わせた表示
- コメント付きの全画面表示：iPad・Mac は本物の全画面、iPhone はプレイヤーを画面いっぱいに広げる疑似全画面（iPhone の全画面再生ではコメントを重ねられないため）

## インストール

ユーザースクリプト拡張（iOS / iPadOS の Safari なら Macaque など）で、次の URL から追加します。

```
https://raw.githubusercontent.com/jinger-box/flow-youtube-chat-lite/main/flow-youtube-chat-lite.user.js
```

更新はこの URL から自動で取得されます（拡張の更新機能を有効にしてください）。

元の Flow Youtube Chat と同時に有効にすると、コメントが二重に流れます。どちらか一方だけを有効にしてください。

## 使い方

- **デスクトップ表示**：プレイヤー右下の操作列に、設定と全画面のボタンが追加されます
- **モバイル表示**：動画タイトルの下の操作列に、同じボタンが追加されます（全画面中はプレイヤー右上に表示）
- iPhone の疑似全画面中は、画面を上に軽くスワイプすると Safari のアドレスバーが小さくなります
- 上の場所が見つからないときは、プレイヤー右上に予備のボタンが出ます

## 既知の制限

- iPhone の全画面再生は iOS 標準のプレーヤーに切り替わるため、コメントを重ねられません
- YouTube の非公開 API を使っているため、YouTube の仕様変更で動かなくなることがあります

## 不具合のとき

設定画面の一番下にある「状態」欄に、チャットの取得状況・最後に取得した時刻・エラーが表示されます。
報告するときは、この欄のスクリーンショットを添えてください。

## 開発

YouTube に依存する値（要素のセレクタ・API 名など）は、スクリプト冒頭の `YT` にまとめています。仕様変更で壊れたときは、まずここを確認します。

```bash
npm install
npx playwright install webkit
npm run check      # 構文・型（JSDoc + tsc）・コードの書き方（Biome）
npm run test:unit  # 単体テスト（ネットワーク不要。API 応答の見本でコメント解析・レーン割り当てなどを確かめる）
npm test           # 実際の YouTube で、ライブ / アーカイブ × デスクトップ表示 / モバイル表示 の 4 通りを確かめる
npm run test:seek  # アーカイブを途中から見て過去に戻したとき、その位置のコメントが流れるか（偽の動画で再現）
npm run test:rewind # ライブを巻き戻したとき、その時点に投稿されたコメントが流れるか（偽のプレイヤーで再現）
```

GitHub Actions でも push 時と毎週月曜に自動で実行され、失敗すると通知が届きます。
GitHub Actions の Linux 版 WebKit は YouTube の映像を再生できないため、そこでは「コメントを受信できること」までを確かめます。
画面にコメントが流れることまで確かめるには、Mac で `npm test` を実行してください。

YouTube の応答の形が変わったときは、`node tests/update-fixtures.mjs <ライブの動画ID> <アーカイブの動画ID>` で見本を作り直します（投稿者名・本文などはダミーに置き換えて保存されます）。

更新を配布するときは、スクリプト冒頭の `@version` を必ず上げてください（上げないと拡張が更新を取得しません）。
